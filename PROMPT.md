# Промпт для агента

Скопируй текст ниже в свой Claude Code, Codex или другой агент. Перед этим замени:

- `[IP]` на IP сервера;
- `root` на своего пользователя, если заходишь не под root;
- `[путь к ключу, если есть]` на путь к SSH-ключу или удали строку.

Не вставляй в чат пароль, токен или содержимое приватного ключа. Агент должен попросить тебя ввести их в терминале, а не в переписке.

```text
Ты помогаешь мне поднять Claude Code на моём VPS и работать с ноутбука по SSH.
Цель: Claude Code крутится на сервере, я подключаюсь из терминала ноутбука, сессия живёт в tmux, Anthropic видит IP сервера.

Мои данные:
- IP сервера: [IP]
- Вход: root или [пользователь]
- SSH-ключ: [путь к ключу, если есть]
- Новый пользователь: dev
- ОС: Ubuntu 24.04

Работай так:
1. Сначала только чтение. Покажи uname -a, /etc/os-release, free -h, df -h /, getent passwd, ss -tlnp, sshd -T, ufw status, systemctl list-units --type=service --state=running.
2. Если на сервере есть чужие сервисы, пользователи или ufw уже активен, остановись и спроси меня. Не трогай nginx, docker, базы, чужие папки и чужие ключи.
3. Покажи план изменений и жди моего «ок». В плане: пользователь, ключи, пакеты, ufw, fail2ban, установка Claude Code.
4. После «ок» делай по шагам и после каждого шага показывай результат:
   - создай dev, добавь в sudo, положи мой ключ в /home/dev/.ssh/authorized_keys, права 700 на папку и 600 на файл, владелец dev;
   - проверь, что я захожу как dev в отдельном окне, только потом закрывай root;
   - поставь tmux, git, curl, ufw, fail2ban;
   - разреши OpenSSH в ufw и включи его;
   - выключи PasswordAuthentication только после проверки входа по ключу, через /etc/ssh/sshd_config.d/00-no-password.conf, сделай backup sshd_config и проверь sshd -t перед reload;
   - включи fail2ban и покажи fail2ban-client status sshd;
   - установи Claude Code от имени dev через официальный установщик, добавь ~/.local/bin в PATH, покажи claude --version.
5. Не запускай claude login за меня, не проси пароль или токен в чате. В конце дай точную команду, которой я сам войду в аккаунт, и что я должен увидеть.
6. Проверь: whoami, hostname, curl -s https://ifconfig.me, ss -tlnp, ufw status, tmux -V, claude --version. Покажи вывод.
7. Дай отчёт: что изменено, что проверено, как откатить. Откат: удалить пользователя dev, вернуть sshd_config из backup, выключить ufw, если он был выключен.
8. Никаких RDP, VNC, открытых 3389, секретов в git и логах.

Если данных не хватает, задай вопрос и остановись. Не угадывай.
```

## Если агент работает прямо на сервере

Убери из промпта первые строки про SSH-вход и оставь только проверку и установку. Перед этим сам зайди на сервер под `root` или под своим пользователем.

## Что проверить в ответе агента

- Он начал с чтения, а не с `ufw enable`.
- Он не трогал чужие сервисы и не менял `nginx`, `docker`, базы.
- Он проверил вход по ключу до того, как выключить пароль.
- Он сделал backup `sshd_config` и прогнал `sshd -t`.
- Он не просил пароль или токен в чате.
- В конце есть команда входа и откат.
